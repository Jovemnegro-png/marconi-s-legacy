# Marconi's Legacy

Crie um site COMPLETO, PREMIUM, RESPONSIVO e com aparência de site desenvolvido por uma agência profissional para a Barbearia Marconi, localizada na Rua Marconi, 67 — República, São Paulo/SP.

INFORMAÇÕES REAIS DO NEGÓCIO

Nome: Barbearia Marconi

Categoria: Barbearia / Salão de Beleza

Endereço: Rua Marconi, 67 - República, São Paulo - SP, 01004-000

Telefone/WhatsApp: +55 11 99464-8174

Avaliação: 4,8 estrelas

Total de avaliações: 786

Score: 92

Use essas informações de forma natural no site.

OBJETIVO

O site deve transmitir imediatamente:

sofisticação

masculinidade

tradição

confiança

experiência premium

atendimento profissional

O principal objetivo é fazer o visitante agendar um horário ou entrar em contato pelo WhatsApp.

Não quero um site com aparência de template, landing page genérica ou site criado por IA.

DIREÇÃO VISUAL

Crie uma identidade visual inspirada em barbearias premium de São Paulo.

Estética:

urbana

elegante

masculina

sofisticada

contemporânea

minimalista

cinematográfica

Use fundo predominantemente escuro, com preto, grafite e tons neutros.

Utilize uma cor de destaque sofisticada, como dourado envelhecido ou bronze, mas de maneira discreta.

Evite:

gradientes exagerados

excesso de elementos

cards demais

bordas arredondadas em tudo

ícones genéricos

emojis

aparência de dashboard

visual "startup"

textos exageradamente comerciais

elementos que façam parecer um template de IA
